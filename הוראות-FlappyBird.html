כל פעם: קודם בוחרים משמאל ב-Hierarchy, ואז משנים מימין ב-Inspector.

איפה הקוד (רק לקריאה)

אתה לא מקליד קוד ביוניטי. הקוד כבר כתוב.

  1. למטה ב-Project לחץ Assets
  2. לחץ על התיקייה Scripts
  3. לחיצה כפולה על קובץ (למשל BirdController) תפתח אותו ב-Cursor

איפה אתה עכשיו

כבר סיימת: מצלמה, צבע רקע, אובייקט Background, ויש שמיים בסצנה.

לפני שממשיכים, סדר את הרקע כך:

  1. משמאל, אם יש גם BgLeft וגם background — מחק את הריבוע הישן BgLeft (Delete)
  2. לחץ על האובייקט עם השמיים
  3. ימין: שנה את השם ל-BgLeft
  4. ימין, Position: X = 0   Y = 0   Z = 0
  5. ימין, Sorting Layer = Background

ב-Hierarchy צריך להיראות כך:

Background
  BgLeft

5. להשלים את הרקע — עותק ימין

משמאל: Hierarchy. ימין: Inspector. סרגל עליון: Edit / GameObject

  1. משמאל לחץ על BgLeft
  2. למעלה: Edit → Duplicate (או המקשים Ctrl+D)
  3. ימין: שנה את השם ל-BgRight
  4. ימין, Position X = 18   Y = 0   Z = 0
  5. משמאל לחץ על Background (האב, לא הילדים)
  6. ימין, בסקריפט Scroll Repeater:
    • Left Piece — גרור משמאל את BgLeft לתוך השדה
    • Right Piece — גרור את BgRight
    • Width = 18
  7. שמירה: Ctrl+S

6. קרקע

  1. לחץ במקום ריק ב-Hierarchy
  2. למעלה: GameObject → Create Empty
  3. ימין: שם = Ground
  4. Position: X 0   Y -3.65   Z 0
  5. ימין, כפתור Add Component → חפש Scroll Repeater
  6. שוב Add Component → Box Collider 2D
  7. ימין למעלה, Tag → בחר Hazard
  8. ב-Box Collider 2D: Size X 40 , Size Y 0.4 , Offset Y -0.2
  9. משמאל לחץ על Ground
  10. למעלה: GameObject → 2D Object → Sprites → Square
  11. שנה שם ל-GroundLeft
  12. ימין, Sprite: למטה ב-Art גרור את ground לשדה Sprite
  13. Sorting Layer = Ground
  14. Position = 0 , 0 , 0
  15. Ctrl+D על GroundLeft → שם GroundRight → Position X = 10.5
  16. לחץ על Ground. ב-Scroll Repeater: Left = GroundLeft , Right = GroundRight , Width = 10.5

אם גררת תמונה ל-Hierarchy בטעות (כמו ברקע) — מחק את הריבוע הישן, ושנה את שם התמונה לשם שביקשתי.

7. תקרה

  1. GameObject → Create Empty → שם Ceiling
  2. Position: X 0   Y 5.1   Z 0
  3. Add Component → Box Collider 2D
  4. Size X 40 , Size Y 0.4
  5. Tag = Hazard

8. ציפור

  1. GameObject → 2D Object → Sprites → Square → שם Bird
  2. Position: X -1.4   Y 0   Z 0
  3. Sprite: גרור מ-Art את bird_1
  4. Sorting Layer = Bird
  5. Add Component → Rigidbody 2D
    • Body Type = Kinematic
    • Gravity Scale = 0
    • סמן Freeze Rotation Z
    • Collision Detection = Continuous
  6. Add Component → Circle Collider 2D → Radius = 0.32
  7. Add Component → Bird Controller
  8. ב-Flap Frames שנה Size ל-3: 0 = bird_0 , 1 = bird_1 , 2 = bird_2
  9. את Game Audio נחבר בשלב 10

9. צינורות

  1. Create Empty → שם PipePair → Position X 12
  2. Add Component → Pipe Pair
  3. סמן את PipePair → 2D Object → Sprites → Square → שם PipeBottom
  4. גרור pipe לשדה Sprite
  5. Sorting Layer = Pipes
  6. Position 0 , -1.2 , 0 | Scale 1 , 1 , 1
  7. Add Component → Box Collider 2D | Tag = Hazard
  8. Ctrl+D → שם PipeTop
  9. Position 0 , 1.2 , 0 | Scale 1 , -1 , 1
  10. על PipePair: Top = PipeTop , Bottom = PipeBottom
  11. למטה פתח Assets / Prefabs
  12. גרור את PipePair מה-Hierarchy אל התיקייה Prefabs
  13. מחק את PipePair מה-Hierarchy (Delete). הקובץ בתיקייה נשאר
  14. Create Empty → שם PipeSpawner
  15. Add Component → Pipe Spawner
  16. Pipe Prefab: גרור מ-Prefabs את PipePair
  17. Pool Size = 6

10. מערכות וסאונד

  1. Create Empty → שם Systems
  2. Add Component → Game Manager
  3. Add Component → Audio Source
  4. Add Component → Game Audio
  5. ימין ב-Game Audio, גרור מתיקיית Audio:
    • Flap Clip ← flap
    • Point Clip ← point
    • Hit Clip ← hit
    • Die Clip ← die
  6. משמאל לחץ Bird → ימין ב-Bird Controller → Game Audio ← גרור את Systems

11. תפריטי המשחק (UI)

אם קופץ חלון Import TMP Essentials — לחץ Import.

  1. למעלה: GameObject → UI → Canvas
  2. על Canvas, ב-Canvas Scaler: Scale With Screen Size , גודל 1920 x 1080
  3. סמן Canvas → GameObject → UI → Panel → שם ReadyPanel
  4. סמן ReadyPanel → UI → Text - TextMeshPro → שם ReadyHint
    טקסט: TAP / SPACE   יישור מרכז   גודל בערך 72
  5. סמן Canvas → TextMeshPro → שם ScoreText
    טקסט 0 , למעלה במרכז , גודל 96. כבה את הוי ליד השם (לא פעיל בהתחלה)
  6. סמן Canvas → Panel → שם GameOverPanel → כבה את הוי
  7. בתוך GameOverPanel צור:
    • טקסט FinalScore
    • טקסט BestScore
    • תמונה UI → Image בשם Medal
    • כפתור UI → Button - TextMeshPro בשם RestartButton עם הכיתוב RESTART
  8. לחץ על Canvas → Add Component → Game UI

13. שמירה כדי שירוץ במחשב אחר

  1. Ctrl+S
  2. למעלה: File → Build Settings (או Build Profiles)
  3. אם אין ברשימה SampleScene לחץ Add Open Scenes
  4. סמן וי ליד הסצנה
  5. Ctrl+S שוב

14. איך בודקים את המשחק

  1. למעלה במרכז לחץ על המשולש Play
  2. מקש רווח או קליק — הציפור קופצת
  3. צינורות מגיעים מימין, ניקוד עולה
  4. פגיעה בצינור/קרקע → מסך סיום → כפתור RESTART
  5. יציאה ממצב בדיקה: לחץ שוב על המשולש

אל תלחץ Play לפני שסיימת את שלבים 5–13. אם משהו נשבר — צילום של החלון Console (למטה) ושל Systems מימין.
