# Flappy Bird (Unity 6000.3.20f1)

Clone of the original Flappy Bird gameplay: tap/space to flap, dodge pipes, score, game over with best score and medals.

## Open the project

1. Install **Unity Hub** and editor **6000.3.20f1** (not 6.5).
2. Hub → **Open** → select this folder.
3. Template: Universal 2D. Open scene `Assets/Scenes/SampleScene.unity`.

## Controls

- Mouse click, Space, or Up Arrow to flap / start

## Notes

- Best score is saved locally with `PlayerPrefs`.
- Art and audio are generated from `Flappy Bird > Generate Art And Audio` (already included under `Assets/Art` and `Assets/Audio` after that menu is run).
